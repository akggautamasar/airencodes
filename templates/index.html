How it works

1

Lossless PNG only

Data is packed directly into RGB pixel channels. PNG never alters pixels, so data is never altered — unlike JPEG.

2

SHA-256 verified

Every chunk and the complete file gets a SHA-256 hash stored in the header. Decode refuses to output anything that doesn't match.

3

Self-describing

The original filename, part index, and both checksums are embedded in every PNG. Works even if the image is renamed or moved.
