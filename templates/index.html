How it works

1

Lossless PNG only

Data is packed into raw RGB pixel channels. PNG never alters pixels, so your data is never altered — unlike JPEG.

2

AES-256-GCM encryption

Optional password protection. Key is derived with PBKDF2-SHA256 (260k rounds). Wrong password → decryption fails, nothing is saved.

3

SHA-256 verified

Every chunk and the full file has a SHA-256 hash embedded. Decode refuses to output anything that doesn't match exactly.

4

Self-describing

Original filename, part index, and checksums live inside every PNG. Works even if the image is renamed or moved.
